Chapter 1 : Introduction :
HTML, which stands for HyperText Markup Language, is the standard markup language used to create and structure pages on the World Wide Web.
It acts as the skeleton or structural backbone of a website, providing the core framework that web browsers read to render elements like headings, text blocks, hyperlinks, and images.
Created by Tim Berners-Lee in 1991, HTML uses a system of elements defined by tags enclosed in angle brackets to organize digital content semantically.
While it handles the basic layout and text flow, it works in tandem with Cascading Style Sheets (CSS) for visual styling and JavaScript for dynamic interactivity.
Today, its latest standard iteration, HTML5, powers modern cross-platform web development with native multimedia support.

Chapter 2 : What is HTML?
HTML stands for HyperText Markup Language, and it is the standard markup language used to create and structure the content of web pages.
It acts as the structural skeleton of a website, providing the core framework that tells a web browser how to display text, images, links, and other media.
HTML is not a programming language; it cannot execute logical operations or dynamic calculations. Instead, it uses a declarative system of tags to label pieces of content so web browsers understand their meaning and semantic purpose.
How HTML Works
When you visit a website, your web browser requests an HTML document from a server. The browser reads this file and processes its elements to render a visual web page.

Chapter 3 : What is javascript?
JavaScript (JS) is a lightweight, interpreted programming language used to create dynamic and interactive features on websites.
Along with HTML (which structures web content) and CSS (which designs it), JavaScript is one of the three core technologies powering the World Wide Web.
Core Technical Characteristics
Code runs line-by-line in the browser via Just-In-Time (JIT) compilation rather than needing manual compilation beforehand.
Variable types are determined automatically at runtime rather than being declared ahead of time.
It executes one task at a time, but efficiently manages heavy loads using asynchronous programming models.
: Objects inherit properties directly from other objects instead of relying strictly on traditional class hierarchies.

Chapter 4 : What is CSS
CSS stands for Cascading Style Sheets.
It is a style sheet language used to format and style the visual presentation of web pages written in HTML.
While HTML acts as the structural skeleton of a website, CSS functions as the interior designer, controlling properties like colors, fonts, layouts, spacing, and animations.
